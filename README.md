# 网易云音乐 · DSH 插件（dsh-netease-music）

在 DSH 里直接看、直接控 Windows 版网易云音乐：一个独立控制面板 + 14 个可对话调用的工具。

- 面板：正在播放、封面歌词、进度条、音量、播放队列、歌单管理、主题与背景
- 工具：状态查询、点播、切歌、搜索、歌单增删、歌词读取
- 进度：读取客户端播放条的真实时间，1 秒采样 + 本地插值，歌词逐句跟随

> 这是一个**本机自动化插件**：通过调试端口读取并控制你电脑上正在运行的网易云客户端。

当前版本 **0.4.7**。仓库：<https://github.com/sdfedsfsdf/dsh-netease-music>。

## 权限、外部服务与失败边界

| 能力 | 用在哪 | 范围 |
| --- | --- | --- |
| 本地调试端口 | 读取播放状态、派发播放控制 | 仅连 `127.0.0.1:<cdpPort>`（默认 9223），只监听本机 |
| 文件读写 | 保存端口配置、登录 cookie 缓存、运行日志 | 仅在 `$DSH_HOME/netease-music/` 下，不写插件目录以外的地方 |
| 网络 | 调网易云官方接口（搜索、歌单、歌词） | 只访问 `music.163.com` 自家接口，不带第三方上报 |
| 账号凭据 | 从客户端页面读已登录 cookie | 只存本机 `cookie.json`（0600），不上传、不写日志 |
| 子进程 | 仅在「启动客户端」时拉起网易云 | 固定路径 `cloudmusic.exe`，无安装期脚本、无 shell 拼接 |

**失败边界**：客户端没开/没调试端口 → 面板显示未连接并提示启动；客户端改版 → 进度或控制失效但不写坏数据；接口失败 → 返回错误对象而不是抛出中断。

## 功能

**控制面板**（侧栏「网易云」，独立整页）

| 区块 | 能做什么 |
| --- | --- |
| 顶部状态 | 客户端是否连上、登录账号、启动客户端、刷新登录 |
| 正在播放 | 封面 / 歌名 / 歌手 / 专辑 / 时长 / 队列位置 / 播放模式；播放暂停、上一首、下一首、喜欢 |
| 进度条 | 真实进度，可拖动跳转；拖动时浮出时间提示 |
| 音量 | 0–100 滑杆，松手才发请求 |
| 歌词 | 跟随高亮、自动滚动、原文/译文切换、点任意一句跳转 |
| 播放队列 | 完整队列；支持**队列内搜索**，结果独立显示，不影响原队列内容与顺序 |
| 搜索 | 歌曲 / 歌单 / 歌手，可播放或加入自己的歌单 |
| 我的歌单 | 新建、整张载入、整张播放、逐首播放、**歌单内搜索**、删除（带确认） |

## 安装

要求：Windows、DSH ≥ 0.1.7、Node ≥ 20，已安装网易云音乐客户端。

```powershell
dsh plugin --profile desktop add "路径\dsh-netease-music-0.4.6.tgz"
```

安装后确认该 profile 的 `dsh.profile.bundles` 里有 `dsh-netease-music`，然后**完全退出并重新打开 DSH**。

从源码安装：

```powershell
dsh plugin --profile desktop add "link:你的源码目录"
```

## 使用

1. 点侧栏「网易云」打开面板。
2. 顶部若显示未连接，点「启动客户端」——它会重启网易云并带上调试端口（播放会中断几秒）。
3. 登录在网易云客户端里完成，面板只读取已有登录态。
4. 之后即可在面板或对话里点歌、切歌、查歌词。

## 工作原理

- **读/控播放**：网易云客户端是 CEF，用 `--remote-debugging-port` 打开 CDP，在页面里取 webpack require，派发客户端自己的 Redux action。
- **歌单**：从 CDP 取已登录 cookie，走网页版 WEAPI（自实现加密，无第三方依赖）。
- **进度**：客户端 store 没有实时位置，改读底部播放条 `01:50 / 02:20` 的 DOM 文本，缓存节点后只读 `textContent`。
- **歌词**：`/weapi/song/lyric`，解析 LRC 为 `[{time,text,tr}]`，支持多时间戳与 offset。
- **数据位置**：`$DSH_HOME/netease-music/`（`config.json`、`cookie.json`、`netease.log`），**不在插件包内**。

## 注意事项

**安全与隐私**

- 调试端口只应绑定本机，**不要暴露到公网**；同机其他程序理论上可连上该端口操作客户端。
- `cookie.json` 是登录凭证，权限 0600。**不要分享、不要提交到仓库**；本仓库与安装包都不包含它。
- 插件不上传任何数据；但搜索、歌单、歌词会请求网易云官方接口，属于正常客户端行为。

**兼容性**

- 针对 Windows 客户端 3.1.41.205564 实测，网易云改版可能失效（届时面板会显示「客户端没给出进度」）。
- 进度是**秒级**精度加插值，不是毫秒级音频时钟；LRC 本身不准时仍会不同步。
- 队列 / 歌单上限 5000 首；部分队列项元数据可能延迟补齐。
- `playOneCycle` / `playAi` 播放模式未逐项实测。
- 歌手搜索结果目前按歌单流程处理，不要当作可靠的「播放某歌手全部作品」入口。

**会修改账号数据的操作**

- 新建歌单、加歌、删歌会真实写入你的网易云账号，删歌前请核对对象。
- 「启动客户端」会关掉当前客户端进程，播放中断。

**界面设置**

- 主题、背景图、字号存在浏览器 localStorage，按 DSH 地址（端口）隔离；换端口或清站点数据后需重设。
- 背景图仅本地读取，不上传，上限 8MB。

## 常见问题

**面板显示未连接**
确认网易云正在运行且带调试端口，点「启动客户端」重启一次。

**进度不动**
客户端改版后播放条结构可能变化，此时进度显示为空，但拖动跳转仍可用。

**歌名显示「（未知歌曲）」**
通过 `playing/play` 推入的队列项，客户端只存 id，插件会按 id 补元数据，稍等或刷新即可。
